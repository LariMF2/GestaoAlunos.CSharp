# 🎓 Sistema de Gestão de Alunos (C#)

Aplicação de consola desenvolvida em C# (.NET) para gestão e registo de alunos de uma turma/curso. Projeto desenvolvido como trabalho prático no âmbito do percurso académico em Engenharia de Informática / Sistemas de Informação.

---

## 📌 Funcionalidades

- **➕ Adicionar Aluno:** Registo de número de estudante, nome e idade com validação automática de dados.
- **📋 Listar Alunos:** Exibição estruturada de todos os alunos registados.
- **🔍 Procurar Aluno:** Pesquisa flexível por número de estudante ou nome (sem diferenciação de maiúsculas/minúsculas).
- **❌ Remover Aluno:** Remoção de registos com pedido de confirmação de segurança.
- **🛡️ Validações Robustas:** Proteção contra entradas inválidas (textos em campos numéricos, idades irrealistas e duplicados de número de estudante).

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C#
- **Plataforma:** .NET Console Application
- **Paradigmas:** Programação Orientada a Objetos (POO)
